Getting Started

Clone this fork, install it with pip install -e ., and set pc.config.cloudy_exe to your local Cloudy binary before running models.

  • Use CloudyInput to write model input files.
  • Use CloudyModel to read output files and inspect results.
  • Use C3D to combine 1D runs into 3D structures.
